2. Environment Setup

Follow the steps below to set up the development/production environment.

  1. Clone repository: git clone ...
  2. Install dependencies: pip install -r requirements.txt
  3. Set up database: python manage.py migrate
  4. Run server: uvicorn main:app --reload

3. Configuration

Environment variables: DATABASE_URL, SECRET_KEY, etc.

4. Monitoring & Logging

Logs are stored in /var/log/app. Use Prometheus + Grafana for monitoring.
